# designtradgard

Webbplats byggd med TanStack Start, React och Tailwind. Ingen backend: varken Supabase eller något API är kopplat.
Formulären (`src/lib/formular.ts`) är en stub som inte skickar något – koppla in en mottagare där.

```sh
bun install
bun run dev
```

Företagsuppgifter och tjänster ligger i `src/lib/foretag.ts` och `src/lib/tjanster.ts`.
